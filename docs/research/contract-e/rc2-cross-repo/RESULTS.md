## INFERENCE

The tested pipeline stages support a common **authority interface pattern** while preserving distinct authority domains.

The strongest currently supported architecture is not:

`one conclusion -> one generic authorized flag`

and not:

`one universal semantic/authorization evaluator`.

`authoritative observation/artifact -> truthful participant binding -> typed jurisdiction domain -> applicable operation/target -> local semantic or action evaluation`.

Epistemic authority and action authority can share the same structural grammar without becoming the same authority.
