## RC1 posture

RC1 does not discard the RC0 findings. It changes the order of proof:

1. establish the stable CAL epistemic-result information surface;
2. prove that human reports are derived views of that surface;
3. preregister multiple materially different consumers;
4. test information sufficiency and field-family minimality across them;
5. independently assess whether the current Decision Engine/Gate architecture is sufficient;
6. only then decide Contract-C schema/version and any Decision Engine production architecture.

The locked Contract-B 1.2.0 boundary remains fixed during this program unless new evidence specifically falsifies an upstream assumption.
