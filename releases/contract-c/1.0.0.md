# Contract C 1.0.0

Contract C 1.0.0 is the first canonical CAL → downstream-consumer contract. It is an immutable, decision-agnostic representation of CAL-attributable result state, exactly bound to its Contract-B input and exact CAL/policy identity.

## Release identity

- Contract version: `1.0.0`
- Namespaced immutable tag: `contract-c-v1.0.0`
- Canonical owner: `camerontjs-dot/apparatus-contracts`

- Frozen canonical fixture SHA-256: `7a66583e332be4901d13ba9f2d7e12419938c77a41b83223a4b0946ad529b7a1`

The release workflow attaches a machine-readable release-lock receipt containing the exact release commit and pinned producer/consumer identities.

## What changed

This release establishes the minimal canonical Contract C surface justified by the RC2 attribution, producer-sufficiency, clean-handoff, independent-consumer, CAL producer-conformance, and clean-consumer release-conformance evidence.

It preserves exact Contract-B binding, CAL/policy identity, proposition and evidence references, retained residual/non-deciding contributions, aggregate measurement basis, explicit assessment/execution state, terminal basis and demonstrated causal multiplicity. It uses deterministic UTF-8 JSON canonicalization, content-derived object identity, and a separate normative whole-object SHA-256 binding.

## Compatibility

This is the first canonical Contract C version, so no migration from an earlier production Contract C is required. Exact v1 objects reject unknown fields. Future incompatible required shape or semantic reinterpretation requires a major-version decision; additive change is minor only when legitimate v1 consumer compatibility is demonstrated.

Contract B remains independently versioned and is not changed by this release.
